# **Overview**

I made this tool to make designing Dofus guild emblems easier. Instead of typing in random numbers, you can just look through the lists and pick what you want without buying the Guildalogem.

NO more inactivity logout for picking too long! 😆

Try it out <a href="https://desiwah.github.io/Dofus-Emblemer/" target="_blank">HERE</a>! 👈🏻
